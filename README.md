#  100 Java Programs

> A hands-on collection of 100 Java programs created to strengthen programming fundamentals, logical thinking, and problem-solving skills.

##  About This Repository

This repository contains **100 Java programs** developed as part of my programming fundamentals practice.

The main goal of this repository is not just to write code, but to **build a strong foundation in programming by solving problems step by step**.

The programs start with basic Java concepts and gradually move towards conditional statements, loops, strings, patterns, arrays, and more challenging problems.

This repository serves as a record of my learning journey and helps me track how my programming fundamentals and problem-solving skills improve over time.

* Improve logical and analytical thinking

##  Repository Structure

The programs are organized according to the concepts they focus on:

##  How to Run

### 1. Clone the repository

```bash
git clone https://github.com/vishalpatelspidermangit/100-programs.git
```

### 2. Open the repository

```bash
cd 100-programs
```

### 3. Navigate to any program

For example:

```bash
cd basic
```

### 4. Compile a Java program

```bash
javac program1.java
```

### 5. Run the program

```bash
java program1
```

> Make sure Java/JDK is installed and configured on your system.
